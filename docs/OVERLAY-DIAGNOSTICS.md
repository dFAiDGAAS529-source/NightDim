# Диагностика жёлтой рамки

Windows Graphics Capture рисует системную рамку вокруг окна или дисплея, который захватывается. Если запущено несколько сеансов захвата, рамка может появиться вокруг каждого выбранного объекта. Исключение собственного слоя NightDim из поддерживаемых видов захвата через `WDA_EXCLUDEFROMCAPTURE` управляет содержимым записи. Системная индикация захвата относится к отдельному механизму Windows. [Windows Graphics Capture](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/screen-capture) · [SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)

## Проверка NightDim

На Windows 11 build 26200 проверили нативные окна слоя на трёх SDR-дисплеях 1920 × 1080 с X = −1920, 0 и 1920. При alpha 8 внешний и клиентский прямоугольники всех окон точно совпали с границами своих дисплеев. У окон были стили `WS_POPUP`, `WS_VISIBLE` и `WS_CLIPSIBLINGS`, расширенный стиль `0x080800A8` и affinity `0x11`. Код отрисовывает клиентскую область чёрной кистью. Фокус сохранился, тестовые окна удалились.

В ходе краткого теста `BitBlt` считывал пиксели на четырёх краях и в центре собственных белых образцов. На двух дополнительных дисплеях все пять точек потемнели равномерно с `#FFFFFF` до `#F7F7F7`. На основном дисплее в четырёх крайних точках **до создания слоя** уже был жёлтый `#FFE640`. При включении слоя центр потемнел с `#FFFFFF` до `#F7F7F7`, края сохранили жёлтый оттенок `#FDE43E`. Отдельный проход без тестовых окон и без слоя обнаружил золотистую полосу шириной два пикселя на всех четырёх краях основного дисплея.

Наблюдаемая рамка существовала независимо от окон NightDim и соответствует индикации Windows Graphics Capture. Процесс, которому принадлежала сессия захвата, не определяли. Геометрия и цвет слоя NightDim исправления не потребовали.

## Как различить причины

1. Выключите эффект NightDim и завершите NightDim через трей, оставив захват запущенным. Если рамка сохраняется, источник находится вне слоя NightDim.
2. Завершите свою сессию записи, демонстрации или PC-агента обычной командой остановки. Проверьте, исчезла ли рамка. При необходимости повторите запуск одного средства захвата и проверьте, совпадает ли контур с его выбранным окном или монитором.
3. С выключенным захватом запустите NightDim и установите умеренную яркость, например 50%. Сравните края при выключенном и включённом эффекте. Если видна светлая полоса только при эффекте, запишите монитор, масштаб, разрешение и расположение дисплеев. Эти данные помогут воспроизвести ошибку позиционирования.
